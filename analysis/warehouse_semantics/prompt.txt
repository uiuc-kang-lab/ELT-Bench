Separate independent numeric casts inside one composite hash, but retain the common parent context and do not infer each leaf individually fixes the whole hash. For independent identical leaf text in separate projections, include enough literal parent/alias context in expression to distinguish the sites. Only final evaluated models are denominator members. Upstream/helper/staging SQL supplies contextual causal evidence; expressions occurring only there are not counted directly as evaluated-model sites.
